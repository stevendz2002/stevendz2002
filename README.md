### ✦ About me

I'm **Steven**, a **Systems Engineering student at UCEVA, Colombia**, with a focus on **backend development** using **Java, Spring Boot, and PostgreSQL**.

I enjoy designing APIs, organizing code with **Clean Architecture**, working with databases, and turning academic ideas into deployed applications. I also build interactive frontend experiences with **Angular** and **TypeScript**.

- 🌙 **Current focus:** Java · Spring Boot · PostgreSQL · REST APIs
- 🏗️ **Interested in:** software architecture, testing, Docker, and CI/CD
- ✨ **Also exploring:** Angular, TypeScript, 3D web experiences, and creative UI
- 💼 **Open to:** backend internships, trainee/junior opportunities, and collaborations
- 🌎 **Based in:** Colombia
